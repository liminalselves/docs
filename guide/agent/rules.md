# 规则

规则是角色作者写给角色的「行为约束开关」：与[禁止行为](/guide/agent/create#安全与边界)不同，规则可以带开关，让你在会话中自己决定角色的某些设定是否生效。

## 两种类型

- **常驻规则**：始终生效，你无法关闭。
- **可切换规则**：你可以在会话中自由开启或关闭；作者可以设定它的默认状态。

可切换规则还可能带有「关闭状态提示词」：规则被你关掉后，角色不是单纯忘掉这条设定，而是切换成另一套行为方式（列表中会显示「双向」徽章）。例如「重口 / 轻口」「剧透模式」这类开关，就适合用双向规则实现。

## 会话中的「规则」标签页

在会话的「规则」标签页可以查看当前角色配置的全部规则：

- 顶部显示规则总数、常驻规则数与可切换规则数。
- 每条规则显示名称、简介和当前状态，可切换规则带有开关，点击即时生效，下一轮对话起生效。
- 只显示名称与简介，不会暴露提示词原文。
- 角色没有配置规则时，标签页会显示占位说明。

## 与其他机制的分工

- **禁止行为**：永远生效的安全底线，用户碰不到。
- **世界书**：按关键词按需注入的背景知识。
- **规则**：你可以感知、可以切换的行为模式开关。

## 给创作者

在[角色编辑页](/guide/agent/create)可以配置规则，随角色一起发布：

- 每个角色最多 5 条规则，名称与简介均不超过 50 字。
- 字段包括：规则名称、简介（给用户看，说明这个开关管什么）、开启状态提示词（常驻规则叫「规则内容」）、关闭状态提示词（可选）、类型与默认开启状态。
- 规则随发布快照进入审核，修改规则需要发布新版本才会对社区会话生效。
