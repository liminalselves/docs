# 规则

规则是角色作者为角色设定的行为约束。与人设中的[禁止行为](/guide/agent/create#人设)不同，部分规则可以由用户在会话中开关。

## 规则类型

| 类型 | 说明 |
| ---- | ---- |
| 常驻规则 | 始终生效，用户无法关闭 |
| 可切换规则 | 用户可在会话中开启或关闭，作者可设置默认状态 |

可切换规则可以另填「关闭状态提示词」：开启时注入开启提示词，关闭时注入关闭提示词，列表中显示「双向」标记。没有填写关闭提示词的规则，关闭后不注入任何内容。

## 会话中的「规则」标签页

- 顶部显示规则总数、常驻数和可切换数。
- 每条规则显示名称、简介和当前状态，可切换规则带开关。
- 开关即时保存，下一轮对话起生效。
- 只显示名称和简介，不显示规则内容。
- 角色没有配置规则时显示「当前会话使用的角色没有配置规则」。

## 创作者配置

在[角色编辑页](/guide/agent/create#规则)的「规则」部分配置：

- 每个角色最多 5 条，名称和简介各不超过 50 字。
- 字段：规则名称、简介（向用户说明作用）、类型、规则内容（可切换规则称为「开启状态提示词」）、关闭状态提示词（可选）、是否默认开启。
- 规则随角色版本发布，修改后需要重新发布才会对社区会话生效。
