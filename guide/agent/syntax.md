# 对话语法

与智能体对话时（你和角色的气泡内），排版语法与站内帖子**不同**：对话气泡支持 GitHub 风格 Markdown（GFM）和安全范围内的 HTML；帖子等站内位置使用的 MFM 不会作用于对话气泡。

## Markdown（GFM）

对话气泡支持以下语法（角色输出也遵循同样规则）：

| 语法 | 效果 |
| ---- | ---- |
| `# 标题` `## 二级标题` | 标题 |
| `**加粗**` | 加粗 |
| `*斜体*` | 斜体 |
| `~~删除线~~` | 删除线 |
| `` `行内代码` `` | 行内代码 |
| `- 列表项`（可嵌套） | 无序列表 |
| `1. 第一项` | 有序列表 |
| `> 引用内容` | 引用块 |
| `[链接文字](URL)` | 超链接 |
| \| 列 A \| 列 B \| 形式 | 表格 |
| ```` ```js …代码… ``` ```` | 带语言高亮的代码块 |
| `- [x] 已完成` / `- [ ] 未完成` | 任务清单 |
| 直接换行 | 软换行（同一气泡内换行显示） |

完整规范见 [GFM 规范](https://github.github.com/gfm/)。

## 安全的 HTML

对话气泡同时支持安全范围内的 HTML 标签（如 `<b>`、`<i>`）。`<script>` 等脚本和事件属性等危险内容会被自动过滤移除。

## 表情与贴纸

| 写法 | 说明 |
| ---- | ---- |
| `:表情名:` | 全站自定义表情，嵌入正文内联显示。用户和角色都可以发送；聊天输入框的表情按钮可直接插入 |
| `[[agent_sticker key=标识]]` | 角色专属表情包。由角色发出，单独占一行，以统一大小的方形贴纸图块展示；开启分段输出时独占一个气泡 |

角色专属表情包由创作者在角色编辑页配置（图片 + 使用时机描述），角色根据对话情绪自主选择发送。详见[正则与表情包](/guide/agent/regex-stickers#角色表情包)。

## 手动触发世界书

在消息里写 `[[wb:条目标题]]` 或 `[[wb:条目ID]]`，可以直接点名触发对应的世界书条目（即使关键词没命中）。详见[世界书](/guide/agent/worldbook)。

## MFM 呢？

MFM（站内帖子用的富文本语法，如 `$[x2 放大]`）**不在对话气泡内生效**。想在帖子里用动画效果，参见 [MFM 语法](/guide/misskey/mfm)。
