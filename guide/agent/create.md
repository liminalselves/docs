# 创作角色

进入「智能体 → 创作 → 角色设定」，点击「新建角色」创建自己的角色。角色编辑页按以下几个部分组织。

## 基本信息

![基本信息](/images/agent-create-basic.webp)

- **名称**：角色的名字。
- **简介**：展示在广场卡片和列表上，不会发送给模型。
- **头像**：角色的形象图片。
- **默认生图参考图**：最多 5 张，每张不超过 5MiB。仅在会话选择了支持参考图的[生图](/guide/agent/chat#生图)模型时发送，用于稳定插图里的角色形象。
- **允许公开角色提示词**：开启后，广场详情页会显示完整提示词供其他用户参考，默认关闭。

## 人设

![人设](/images/agent-create-persona.webp)

人设是模型每轮都会读到的内容。

| 字段 | 内容 |
| ---- | ---- |
| 性格与行为 | 角色的性格特点、行为方式 |
| 背景设定 | 角色的经历、身份与世界观 |
| 说话方式 | 语气、称呼、口癖等表达习惯 |
| 禁止行为 | 角色不会做的事，用于约束模型输出（安全边界） |

## 对话与示例

![对话与示例](/images/agent-create-dialogue.webp)

- **开场白**：创建会话时作为角色的第一条消息自动插入，留空则不插入。
- **示例对话**：逐条选择说话方（用户 / 助手）并填写内容，最多 24 条。保存后作为参考示例进入系统提示，模型只用它参考语气，不当作真实聊天记录。

## 世界书

角色的背景知识库，按关键词、手动或常驻方式注入，详见[世界书](/guide/agent/worldbook)。

## 规则

![规则](/images/agent-create-rules.webp)

为角色定义行为规则，最多 5 条。每条规则包含名称、简介（50 字以内，向用户说明作用）和规则内容。

| 类型 | 说明 |
| ---- | ---- |
| 常驻规则 | 始终生效，用户无法关闭 |
| 可切换规则 | 用户可在会话的「规则」标签页开关；可另填「关闭状态提示词」，关闭时注入，留空则关闭时不注入 |

可切换规则可以设置是否默认开启。用户在会话中只能看到规则的名称和简介，看不到规则内容。

## 正则与表情包

- **正则**：对用户消息或 AI 输出做过滤，详见[正则与表情包](/guide/agent/regex-stickers#正则)。
- **表情包**：角色专属贴纸，详见[正则与表情包](/guide/agent/regex-stickers#角色表情包)。

## 版本管理

角色和对话风格都支持版本管理：查看草稿与发布版的差异、历史版本、回滚到之前的版本。

## 测试与发布

1. 新建的角色是**草稿**，可以在创作列表点「开始聊天」测试，测试会话只有自己可见。
2. 点击「提交审核」。
3. 审核通过后发布到广场，其他用户即可使用。广场显示的是已发布版本，草稿里的后续改动要再次发布才会生效。

审核未通过时，作品上会显示外审反馈的分类和原因，修改后可重新提交。对话风格也走同样的流程，见[对话风格](/guide/agent/styles)。

平台对模型的每次输出都有内容审查，违规内容会被拦截。
