# 常见问题

## Aliya Web 提示「刚刚聊的有点累了，休息一下马上回复」？

这是临时限流，稍等片刻便会自行恢复。出现该回复时发送的对应消息不会被记录和保留。若频繁出现，可以[向我们反馈](#遇到-bug-或异常怎么反馈)。

## 切换对话时提示 429 错误？

如果你在 Aliya Web 中进行切换对话等操作时提示 **429 错误**，并且 Misskey 端也提示 "Rate limit exceeded"，说明触发了服务器限流。等候一段时间后即可恢复使用。

## API Token 泄露了怎么办？

立即删除泄露的令牌，防止未经授权的登录：

1. 访问 Misskey 主页，依次点击 **设置 – 连接服务 – 管理访问令牌**。
2. 删除对应的令牌。
3. 重新生成令牌并[重新登录](/guide/third-party#api-登录)。

::: tip
api token 具有账户的完整访问权限，请像对待密码一样保管它。
:::
