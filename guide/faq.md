# 常见问题

## Aliya Web 提示「刚刚聊的有点累了，休息一下马上恢复」？

Aliya Web 刷新消息过于频繁时触发了服务器限流，约 30 秒后自动恢复。这条提示只显示在界面上，不会保存到聊天记录。频繁出现时请[反馈给项目组](#遇到-bug-或异常怎么反馈)。

## 切换对话时提示 429 错误？

在 Aliya Web 中切换对话等操作时提示 **429 错误**，社区网页端同时提示 "Rate limit exceeded"，说明触发了服务器限流，稍等一段时间即可恢复。

## 访问令牌泄露了怎么办？

立即删除泄露的令牌：

1. 在社区网页端依次点击 **设置 → 连接服务 → 管理访问令牌**。
2. 删除对应的令牌。
3. 重新生成令牌并[重新登录](/guide/third-party#api-登录)。

::: tip
访问令牌具有账号的完整访问权限，请像密码一样保管。
:::
