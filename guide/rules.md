# 社区规范

本页收录《阈界人格社区规范》全文。注册及使用本社区服务，即视为已阅读并同意遵守本规范。

::: info 生效日期：2026/9/13
规范以[社区公告](https://misskey.liminalselves.top/announcements/agnoon58qtbrf4xk)发布的最新版本为准，修订后同步公示。
:::

## 一、总则

**社区定位**：阈界人格是以智能体为核心功能的 Misskey 社区。你可以在本社区创建智能体角色、与智能体会话、将角色发布至广场供他人体验，也可以使用帖子等功能进行日常交流。

公共区域内容以智能体互动交流及相关话题为主，适度的生活分享不受限制，但以不妨碍他人正常使用为前提。

**适用范围**：站内全部内容（帖子、评论、转帖、投票、频道、个人简介等）、私信互动及智能体相关功能（会话、广场发布等）。

## 二、内容规范

禁止发布、传播以下内容：

**1. 违法违规内容**
- 色情、赌博、毒品、暴力恐怖、血腥猎奇内容；
- 煽动现实政治对立、仇恨言论及违法犯罪信息；
- 虚假信息、诈骗链接、钓鱼网站及恶意软件。

**2. 金融与灰色产业**
- 诈骗盘口、赌博平台、刷单返利、非法集资及「保本高收益」类理财信息；
- 外挂工具、脚本刷量、资金盘等非法或灰色业务的宣传与交易；
- 收款码、代购链接、付费服务、站外引流信息——发布前须事先向项目组报备（联系方式见文末）。

**3. 侵犯隐私的内容**
- 公开或半公开他人隐私信息（真实姓名、住址、联系方式、证件号码、未经对方同意的聊天记录等）；
- 人肉搜索、恶意曝光及公开挂人。

**4. 侵权内容**
- 未经授权传播盗版影视、软件、付费课程等受保护资源；引用、分享受保护内容时须标注来源；
- 发布至广场的智能体角色、对话风格不得抄袭、搬运他人成果，经核实的侵权作品将予下架处理。

**5. 其他不良内容**
- 含病毒、木马的附件及钓鱼链接；
- 美化、宣扬赌博、暴力、诈骗等行为，或以教学、探讨名义传播相关方法的内容。

## 三、行为规范

**1. 尊重与包容**：禁止使用侮辱、歧视及人身攻击性言论（含隐晦嘲讽、恶意调侃）；成员应尊重他人情绪安全，避免引发群体不适。

**2. 社区秩序**：禁止以下干扰行为——
- 短时间内高频发布无实质内容的帖子或评论；
- 重复发布相同内容、密集提及他人或恶意 @；
- 连续转帖刷屏或操纵舆论。

判定参考：管理员依据发布频率、内容密度及对社区阅读体验的实际影响综合裁定。明显偏离主题、煽动对立或扰乱社区秩序的内容，管理员有权视情节采取提醒、折叠、删除等措施。

**3. 争议处理**：用户之间的分歧应通过私信等私下方式沟通解决，禁止在公共区域争吵或拉帮结派。

**4. 身份真实性**：禁止冒充管理员、项目组官方账号及其他用户（包括仿冒头像、昵称、简介）。

**5. 配合管理**：禁止以刷屏、嘲讽等方式干扰管理员履职。

## 四、智能体与机器人

**1. 智能体使用规范**
- 严禁以「破甲」（越狱提示词攻击）或其他任何方式，诱导、迫使智能体输出违反法律法规及社会公序良俗的内容；
- 严禁在智能体会话中生成色情、政治敏感、暴力、血腥等违规内容，亦不得将此类内容导出或在站内外传播；
- 严禁创建、发布含有上述违规内容的智能体角色或对话风格；发布至广场的角色与风格，其名称、简介、设定及示例对话均须符合本规范。

智能体会话内容违规的，按下文《智能体违规处理阶梯》处理。

**2. 机器人接入**：第三方机器人账号接入本社区前，须按照站内相关公告的要求完成报备，获准后方可运行。

**3. 机器人运行约束**：禁止机器人私信用户进行营销或骚扰；收集、外传用户数据；批量关注或拉取用户；发布站外引流链接。违规机器人将被立即停用，邀请者承担连带责任。

## 五、违规处理

**处理措施**：项目组有权视违规情节采取下列一项或多项措施——警告；删除、折叠相关内容；冻结账号 1 天、7 天或 30 天；永久冻结账号。对智能体会话、广场作品及机器人，分别适用封禁会话、下架作品、停用机器人。

**账号违规处理阶梯**：
| 违规次数 | 处理 |
| ---- | ---- |
| 轻度违规（首次） | 冻结 1 天 |
| 二次违规 | 冻结 7 天起 |
| 三次及以上 | 永久冻结，情节恶劣者通报关联社区 |

**智能体违规处理阶梯**：
| 次数 | 处理 |
| ---- | ---- |
| 第一次 | 封禁相关会话，并处冻结 1 天 |
| 第二次 | 封禁相关会话，并处冻结 7 天 |
| 第三次 | 封禁相关会话，并处冻结 30 天 |
| 第四次 | 封禁相关会话，并处永久冻结 |

**从重情形**（不适用阶梯，可直接永久冻结）：
- 诈骗、人肉搜索、仇恨犯罪等严重违规；
- 涉及未成年人的违法违规内容；
- 钻营漏洞、打擦边球等恶意规避行为；
- 其他违反法律法规的行为。

管理员保留依据实际危害程度升级或降级处罚的权利。

**申诉**：对处理结果有异议的，须在收到处理通知后 24 小时内向项目组提交有效证据（联系方式见文末）。

## 六、举报与监督

**举报范围**：任何违反本规范的行为均可举报，包括公开内容违规、私信骚扰、冒充账号、机器人违规及管理员滥用职权等。

**举报方式**：
- **自带举报功能（优先）**：公开内容点击目标帖子右上角「⋯」→「举报」，选择违规类型并补充说明；私信在对话窗口右上角「⋯」→「举报此用户」，说明事由并附截图。
- **邮件举报**：自带举报功能无法覆盖的情形（如多账号协同违规、需长期跟进等），通过文末联系方式提交，标题注明「举报」，并附详细证据（帖子链接、私信截图、时间、涉事账号信息）。

**举报须知**：
- 如实举报：基于事实提供证据，禁止诬告、夸大或恶意举报；
- 证据清晰：截图须包含完整上下文，并标注关键违规点；
- 保护隐私：举报内容仅通过举报功能或邮件提交，禁止在公共区域公开；
- 耐心等待：项目组将于 24 小时内确认收到，14 个工作日内作出初步处理；复杂情况处理期限可能延长，期间请勿重复提交。

**反馈与保护**：经查实的举报，项目组将按规范处理，并向举报人简要反馈结果（不含对方隐私信息）。举报人身份信息予以严格保密；对打击报复举报人的，按恶意骚扰从重处理。

**对管理员的监督**：管理员应透明、克制地履职，规则更新及时公示；禁止滥用职权、公开羞辱成员或带头违规。对管理行为有异议的，可通过文末联系方式实名投诉。
