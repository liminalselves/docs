# 设置与隐私

通过侧栏「设置」进入。左侧为设置分类，顶部搜索框可直接搜索设置项。

## 个人资料

- 头像、横幅、昵称、个人简介（支持 [MFM 语法](/guide/misskey/mfm) 和 #标签）、生日、所在地、语言。
- **附加信息**：最多 4 条「标签 + 内容」，以表格显示在主页。内容填 URL 且对方网页包含你的主页链接时，会显示已验证图标。
- **被关注时显示的消息**：别人关注你时向对方显示的短消息。
- **接受表情回应**：全部 / 仅点赞 / 仅限非敏感内容等。
- **这是一个机器人账号**、**猫模式**等标记。
- 佩戴[头像挂件](/guide/misskey/achievements#头像挂件)。

## 隐私

| 设置项 | 说明 |
| ------ | ---- |
| 关注请求需要批准 | 开启后别人关注你需要你同意（锁定账号）；只要帖子可见范围不是「仅关注者」，帖子本身仍对所有人可见 |
| 自动允许回关请求 | 锁定账号时，你关注的人申请关注你会自动通过 |
| 隐藏在线状态 | 不向他人显示在线状态 |
| 使账号可见 | 关闭后账号不出现在「发现」中 |
| 要求搜索引擎不索引该用户 | 请求搜索引擎不收录 |
| 拒绝接受生成式 AI 的学习 | 向爬虫声明拒绝 AI 训练 |
| 将回应设置为公开 | 他人可在你主页的「回应」标签看到你发出的回应 |
| 关注 / 关注者列表可见性 | 公开 / 仅关注者 / 私密 |
| 谁可以发起聊天 | 任何人 / 仅关注者 / 仅关注的人 / 仅相互关注 / 没有人 |
| 需要登录才能显示内容 | 你的帖子只对已登录用户显示 |
| 将过去的帖子设为仅关注者可见 / 私密 | 超过指定时长或早于指定日期的帖子自动变为仅关注者可见或仅自己可见；关闭后恢复原可见范围 |

帖子默认可见范围在「偏好设置」中设置。

## 屏蔽与过滤

「设置 → 屏蔽与过滤」：

| 项目 | 效果 |
| ---- | ---- |
| 折叠关键词 | 命中的帖子折叠显示，点击可展开 |
| 屏蔽关键词 | 命中的帖子完全不显示 |
| 打码表情符号 | 指定的表情符号打码显示 |
| 已隐藏的用户（转发） | 只隐藏该用户的转帖 |
| 已隐藏的用户 | 不再显示对方的帖子和通知，可设定隐藏时长 |
| 已屏蔽的用户 | 对方无法关注你、回应你或与你互动 |

关键词数量上限由服务器策略决定。隐藏和屏蔽也可以在对方主页的「…」菜单中操作。

![屏蔽与过滤](/images/misskey-mute-block.webp)

## 通知

- 按类型设置接收范围：全部 / 关注中 / 关注者 / 相互关注 / 指定列表 / 不接收。
- 开启浏览器推送通知，可发送测试通知。
- 支持的类型见[通知类型](/guide/messages#通知类型)。

## 邮箱

绑定邮箱后可选择哪些事件发送邮件通知，以及是否接收服务器公告邮件。

## 安全

| 项目 | 说明 |
| ---- | ---- |
| 修改密码 | — |
| 验证器 | TOTP 两步验证，用验证器应用扫码绑定；设置完成后会给出一次性备用代码，请妥善保存 |
| 安全密钥或 Passkey | 需先设置验证器才能注册；可开启「无密码登录」，只用安全密钥或 Passkey 登录 |
| 登录历史 | 查看近期登录记录 |
| 重新生成登录令牌 | 让所有已登录设备退出 |

![安全设置](/images/misskey-security.webp)

## 服务连接与账户数据

- **服务连接**：生成访问令牌，供 [Aliya Web](/guide/aliya-web)、[第三方应用](/guide/third-party)等外部程序使用；也可查看和撤销已授权的应用。
- **账户数据**：导出所有帖子、收藏的帖子、便签、关注列表、隐藏/屏蔽列表、列表、天线，导出完成后会收到通知，文件保存到网盘。导入功能是否可用由服务器策略决定。

## 多账号与配置文件

- 侧栏底部头像菜单可「添加账户」并在多个账号间切换。
- **配置文件**：客户端设置按设备保存为配置文件（如「PC」「手机」），不建议多设备共用同一配置文件；需要多设备同步的设置项可单独打开「设备间同步」。可以开启自动备份，防止设置丢失。

## 其他

- **偏好设置**：默认可见范围、敏感媒体显示方式、动画、数据节省模式、发帖与聊天行为等。
- **表情符号调色板**：自定义回应和发帖时的常用表情面板，见[回应与表情符号](/guide/misskey/reactions)。
- **网盘设置**：见[网盘](/guide/misskey/drive)。
- 界面、主题、提示音、插件：见[界面、主题与小工具](/guide/misskey/ui-themes)。
- **其他 → 永久注销账户**：账号删除不可撤销，内容较多时需要一段时间，完成后会发邮件通知。
