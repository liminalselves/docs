# 内置游戏

服务器内置两款小游戏，通过侧栏「Misskey Games」进入。

![Misskey Games](/images/misskey-games.webp)

## 泡泡游戏

单人休闲合成游戏：投下道具，相同种类碰撞后合成更大的一级，连锁合成得分更高。

- 模式：NORMAL、SQUARE、YEN、SWEETS。
- 显示最高分、最大连锁，并有各模式近 7 天的排行榜。

## 黑白棋

黑白棋（Reversi）联机对战。

| 功能 | 说明 |
| ---- | ---- |
| 开始对局 | 「自由匹配」随机寻找对手，或「邀请」指定用户 |
| 对局设置 | 选择棋盘、先手/后手、每回合时间限制 |
| 规则选项 | 落子少的一方获胜（奥赛罗）、循环棋盘、无限制放置模式 |
| 其他 | 开始时在时间线发布对局、用头像作为棋子、显示行号和列号 |
| 对局中 | 可认输，超时判负 |
| 观战与回放 | 可观看他人进行中的对局；结束后可逐步回看棋谱 |

「我的对局」「所有对局」列出进行中和已结束的对局。部分游戏行为会计入[成就](/guide/misskey/achievements)。
